API Documentation

API endpoints for interacting with the Notification Microservice.

Send Announcement by Alert Type

POST /api/v1/notifications ADMIN ONLY

Sends an SMS to all users subscribed to a specific alert type. Requires admin authentication.

Request Body (JSON)

{
    "alertId": 1,
    "message": "This is a broadcast for a specific alert type."
}

Responses

  • 200 OK: If the message is successfully queued for sending.
  • 403 Forbidden: If the request is not made by an admin.

Send Direct SMS

POST /api/v1/send/direct

Sends a direct SMS to a specified phone number. This does not require an alert type and is not tied to any user subscription.

Request Body (JSON)

{
    "phoneNumber": "09171234567",
    "message": "This is a test message from the API."
}

Responses

  • 200 OK: If the message is successfully sent.
  • 400 Bad Request: If `phoneNumber` or `message` is missing.

Send Notification to Specific User

POST /api/v1/send/user/{userId}

Sends an SMS to a single user identified by their user ID.

Request Body (JSON)

{
    "content": "Your package has been shipped."
}

Responses

  • 200 OK: If the message is successfully sent.
  • 400 Bad Request: If `content` is missing, or if the user is not found or has no phone number.

Send Notification to All Users

POST /api/v1/send/all

Broadcasts an SMS to every user in the database who has a registered phone number.

Request Body (JSON)

{
    "content": "System maintenance will occur tonight at midnight."
}

Responses

  • 200 OK: Returns a confirmation with the count of users the message was sent to.
  • 400 Bad Request: If `content` is missing.

Get All Alert Types

GET /api/v1/alert-types

Retrieves a list of all available alert types that users can subscribe to.

Responses

  • 200 OK: Returns a JSON array of alert type objects.

Update User Alert Preference

POST /api/v1/users/{userId}/preferences

Sets the preference for a single alert type for a specific user. This is used to subscribe or unsubscribe a user from an alert category.

Request Body (JSON)

{
    "alertId": 1,
    "isEnabled": true
}

Responses

  • 200 OK: If the preference is updated successfully.
